# SecureChat Blockers & Environment Log

This document logs external prerequisites, credentials, or environment items that require user intervention or external configuration.

| ID      | Category       | Item                                     | Impact                                                                           | Mitigation / Status                                                                                                                                                                                                                                                                  |
| ------- | -------------- | ---------------------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| BLK-001 | Firebase       | `google-services.json` missing           | Push notifications cannot reach a physical FCM endpoint without real credentials | Using gitignored placeholder (`apps/mobile/android/app/google-services.json.placeholder`). Push notification logic, foreground/background handlers, and backend dispatcher are fully implemented and unit tested. Replace with real `google-services.json` when deploying to device. |
| BLK-002 | Infrastructure | Docker Desktop Daemon inactive           | Local PostgreSQL container cannot run until Docker Desktop is started            | Docker Compose file provided (`docker-compose.yml`). Unit tests use isolated in-memory/mocked database storage adapters. Start Docker Desktop when running end-to-end API integration tests.                                                                                         |
| BLK-003 | OS / Platform  | iOS Native Build Tools absent on Windows | Cannot build or test `.xcworkspace` / CocoaPods on Windows                       | Mobile application is built with bare React Native targeting Android natively, and cross-platform TypeScript for all business logic, crypto, and UI. iOS project structure and native stubs are preserved for macOS CI/developers.                                                   |
